<Tip>
1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.

Generate images from a text prompt, or edit one primary image with references, an optional mask, and precision controls.

## Models

- **ideogram-v4.5** - Text-to-image generation with quality and size controls
- **ideogram-v4.5-edit** - Edit exactly one primary image, with optional references, masks, and precision controls

## Required parameters

- **model**: `ideogram-v4.5` or `ideogram-v4.5-edit`
- **input.prompt**: Required for both models. Use `1-10000` characters containing non-whitespace text
- **input.image_urls**: Required for `ideogram-v4.5-edit`. Exactly one primary image. Not supported by `ideogram-v4.5`

## Optional parameters

- **n**: Number of output images. Integer from `1` to `8`. Default is `1`
- **quality**: Output quality. Default is `medium`. `ideogram-v4.5` accepts `low`, `medium`, and `high`. `ideogram-v4.5-edit` also accepts `very_low`
- **size**: Output size. See the size rules below
- **reference_image_urls**: Edit only. Up to four reference images without a mask, or at most three when `mask_url` is set
- **mask_url**: Edit only. Must match the primary image dimensions and contain both black edit areas and white preserve areas. Image-content requirements are checked during processing. Requires `size=auto` or an omitted `size`
- **edit_precision**: Edit only. `regular` or `high`. Default is `regular`. `high` restores unchanged pixels and requires `size=auto` or an omitted `size`
- **callback_url**: Optional webhook URL for task completion notification

All image fields accept public HTTP(S) image URLs or image data URIs.

## Size Parameter

`ideogram-v4.5` defaults to `1:1 HD`. It accepts the aspect ratios `1:1`, `1:1 HD`, `4:3`, `3:4`, `16:9`, and `9:16`, or one of these exact sizes:

`1024x1024`, `1024x3072`, `1120x896`, `1152x2944`, `1152x864`, `1248x3328`, `1248x832`, `1280x3072`, `1280x720`, `1280x800`, `1296x3168`, `1440x2560`, `1440x2880`, `1440x720`, `1600x2560`, `1664x2496`, `1728x2304`, `1792x2240`, `2048x2048`, `2240x1792`, `2304x1728`, `2496x1664`, `2560x1440`, `2560x1600`, `2880x1440`, `2944x1152`, `3072x1024`, `3072x1280`, `3168x1296`, `3328x1248`, `720x1280`, `720x1440`, `800x1280`, `832x1248`, `864x1152`, `896x1120`.

`ideogram-v4.5-edit` defaults to `auto`, which preserves the source size.

- A mask, or `edit_precision=high`, requires `auto` or an omitted size.
- Ratio presets and custom `WIDTHxHEIGHT` sizes require an unmasked regular edit.
- Custom edit dimensions must each be at least `256`, divisible by `32`, total at most `4,194,304` pixels, and have an aspect ratio of at most `6:1`.

## Examples

### Generate Image

```json
{
  "model": "ideogram-v4.5",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "prompt": "A ceramic robot with a clean silhouette."
  }
}
```

### Edit Image

```json
{
  "model": "ideogram-v4.5-edit",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "prompt": "Replace the background with a blue studio.",
    "image_urls": [
      "https://example.com/source.png"
    ]
  }
}
```

### High-precision masked edit

```json
{
  "model": "ideogram-v4.5-edit",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "prompt": "Replace the black mask area with flowers.",
    "image_urls": [
      "https://example.com/source.png"
    ],
    "mask_url": "https://example.com/mask.png",
    "reference_image_urls": [
      "https://example.com/flowers.png"
    ],
    "edit_precision": "high"
  }
}
```

## Notes

- `ideogram-v4.5-edit` requires exactly one primary image in `image_urls`.
- Query status through the standard task status API.
- Successful responses return `files`, where generated images use `file_type: image`.
