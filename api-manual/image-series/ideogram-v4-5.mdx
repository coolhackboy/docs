Submission returns a `task_id`. Use [Query Task Status](/api-manual/task-management/status) to track completion, or supply `callback_url` for completion and failure notifications.

## Parameters and combinations

`prompt` is required (1–10,000 characters). `n` defaults to 1 and accepts 1–8. `quality` defaults to `medium`.

Use existing aspect ratios `1:1`, `1:1 HD`, `4:3`, `3:4`, `16:9`, `9:16`, or a supported `WIDTHxHEIGHT` size.

`size` defaults to `1:1 HD`. `quality` accepts `low`, `medium`, and `high`.

Supported exact sizes: `1024x1024`, `1024x3072`, `1120x896`, `1152x2944`, `1152x864`, `1248x3328`, `1248x832`, `1280x3072`, `1280x720`, `1280x800`, `1296x3168`, `1440x2560`, `1440x2880`, `1440x720`, `1600x2560`, `1664x2496`, `1728x2304`, `1792x2240`, `2048x2048`, `2240x1792`, `2304x1728`, `2496x1664`, `2560x1440`, `2560x1600`, `2880x1440`, `2944x1152`, `3072x1024`, `3072x1280`, `3168x1296`, `3328x1248`, `720x1280`, `720x1440`, `800x1280`, `832x1248`, `864x1152`, `896x1120`.

## Examples

```json
{
  "model": "ideogram-v4.5",
  "input": {
    "prompt": "A ceramic robot with a clean silhouette."
  }
}
```

## Task results

The query response uses the common task structure: `task_id`, `status`, `progress`, `files`, and `error_message`. A finished task has `status="finished"`; each result file has `file_url` and `file_type`. Preserve the task ID while polling.

Images appear as `file_type="image"`.
