Submission returns a `task_id`. Use [Query Task Status](/api-manual/task-management/status) to track completion, or supply `callback_url` for completion and failure notifications.

## Available models

- `ideogram-v4.5`: Generate images from a prompt with quality and size controls.
- `ideogram-v4.5-edit`: Edit exactly one primary image with references, optional masks, and precision controls.

## Parameters and combinations

- `prompt`: Required for both models, 1–10,000 characters with non-whitespace content.
- `n`: Number of output images for both models; defaults to 1 and accepts 1–8.
- `quality`: Defaults to `medium` for both models. `ideogram-v4.5` accepts `low`, `medium`, and `high`; `ideogram-v4.5-edit` also accepts `very_low`.
- `size`: `ideogram-v4.5` defaults to `1:1 HD` and accepts the aspect ratios `1:1`, `1:1 HD`, `4:3`, `3:4`, `16:9`, and `9:16`, or an exact size listed below. `ideogram-v4.5-edit` defaults to `auto`, which preserves the source size; ratio presets or custom `WIDTHxHEIGHT` values require a regular unmasked edit. Custom edit dimensions must each be at least 256, divisible by 32, total at most 4,194,304 pixels, and aspect ratio at most 6:1. A mask or `edit_precision=high` requires `auto` or omitted size.
- `image_urls`: Required only for `ideogram-v4.5-edit`; must contain exactly one primary image. Not supported by `ideogram-v4.5`.
- `reference_image_urls`: Optional, `ideogram-v4.5-edit` only. Accepts at most four reference images without a mask, or three with `mask_url`.
- `mask_url`: Optional, `ideogram-v4.5-edit` only. Must match the primary image dimensions and contain both black (edit) and white (preserve) areas. Image-content requirements are checked during processing.
- `edit_precision`: Optional, `ideogram-v4.5-edit` only. Accepts `regular` (default for editing) and `high`; high-precision editing restores unchanged pixels.

All image fields accept public HTTP(S) image URLs or image data URIs.

For `ideogram-v4.5` generation, the supported exact sizes are: `1024x1024`, `1024x3072`, `1120x896`, `1152x2944`, `1152x864`, `1248x3328`, `1248x832`, `1280x3072`, `1280x720`, `1280x800`, `1296x3168`, `1440x2560`, `1440x2880`, `1440x720`, `1600x2560`, `1664x2496`, `1728x2304`, `1792x2240`, `2048x2048`, `2240x1792`, `2304x1728`, `2496x1664`, `2560x1440`, `2560x1600`, `2880x1440`, `2944x1152`, `3072x1024`, `3072x1280`, `3168x1296`, `3328x1248`, `720x1280`, `720x1440`, `800x1280`, `832x1248`, `864x1152`, `896x1120`.

## Examples

### Text-to-image generation

```json
{
  "model": "ideogram-v4.5",
  "input": {
    "prompt": "A ceramic robot with a clean silhouette."
  }
}
```

### Edit one primary image

```json
{
  "model": "ideogram-v4.5-edit",
  "input": {
    "prompt": "Replace the background with a blue studio.",
    "image_urls": [
      "https://example.com/source.png"
    ]
  }
}
```

### High-precision edit with a mask and reference

```json
{
  "model": "ideogram-v4.5-edit",
  "input": {
    "prompt": "Replace the black mask area with flowers.",
    "image_urls": [
      "https://example.com/source.png"
    ],
    "mask_url": "https://example.com/mask.png",
    "reference_image_urls": [
      "https://example.com/flowers.png"
    ],
    "edit_precision": "high"
  }
}
```

## Task results

The query response uses the common task structure: `task_id`, `status`, `progress`, `files`, and `error_message`. A finished task has `status="finished"`; each result file has `file_url` and `file_type`. Preserve the task ID while polling.

Images appear as `file_type="image"`.
