<Tip>
1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the response result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.
</Tip>

GPT Image 2.6 Fixed runs GPT Image 2.6 Flare or Sunburst with per-image pricing instead of token-based pricing. Choose the variant with `version`: Flare is tuned for speed, and Sunburst for more detailed visuals and more precise, consistent edits. Add reference images to edit or guide the output.

## Models

- **gpt-image-2.6-fixed** — GPT Image 2.6 Flare or Sunburst with per-image pricing

## Required parameters

- `prompt` (string): Image description, 1–32000 characters.

## Optional parameters

- `version` (string): `flare` or `sunburst`. Default is `flare`.
{/* resolution is temporarily hidden for GPT Image 2.6 Fixed; restore this line when it is re-enabled:
- `resolution` (string): `1K`, `2K`, or `4K`. Default is `1K`.
*/}
- `size` (string): `auto`, `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `5:4`, `4:5`, or `21:9`. Default is `1:1`.
- `image_urls` (array of strings): Up to 16 reference image URLs.

## Output

A finished task returns the generated image in `files` with `file_type: image`.

## Examples

- **Text to image with Flare** — sets `prompt`, `version`, `size`.
- **Edit with a reference image using Sunburst** — sets `prompt`, `version`, `image_urls`.

## Notes

- `n` and `num_images` are not supported. Each task returns one image.
- `image_urls` must be an array, even for one image.
- Output is a raster image. Complexity control, SVG output, animated GIF output, and markup-guided edits are not available on this endpoint.
