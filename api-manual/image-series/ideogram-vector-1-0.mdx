Ideogram Vector 1.0 creates editable SVG graphics from a text prompt, or converts one existing image into an SVG. Text generation can follow up to five reference images.

## Models

- **ideogram-vector-1.0/text-to-vector** — Generate SVGs from a prompt, with optional reference images
- **ideogram-vector-1.0/image-to-vector** — Convert exactly one image into an SVG

## Features

- Generate 1–8 SVGs from a prompt, with quality and aspect-ratio controls.
- Guide text generation with 1–5 reference images in `image_urls`. The first image is the primary reference.
- Convert exactly one JPEG, PNG, or WebP image into an SVG, with a detail mode or a simpler shape mode.

## Required parameters

- `prompt` (string): Required for `ideogram-vector-1.0/text-to-vector`. Use 1–9500 characters containing non-whitespace text.
- `image_urls` (array of strings): Required for `ideogram-vector-1.0/image-to-vector`. Exactly one publicly accessible HTTP(S) image URL to convert. JPEG, PNG, or WebP, up to 50 MB.

## Optional parameters

- `image_urls` (array of strings): Optional for `ideogram-vector-1.0/text-to-vector`. 1–5 publicly accessible HTTP(S) reference images. JPEG, PNG, or WebP, up to 10 MB each. The first URL is the primary reference. Omit this field when there is no reference image.
- `quality` (string): Text to vector only. `low`, `medium`, or `high`. Defaults to `medium`.
- `n` (integer): Text to vector only. Number of SVGs, from 1 through 8. Defaults to 1.
- `size` (string): Text to vector only. Aspect ratio. Defaults to `auto`.
- `mode` (string): Image to vector only. `default` keeps finer detail. `simple` uses fewer shapes. Defaults to `default`.

Image fields also accept image data URIs.

## Size

Text to vector accepts `auto`, `1:1`, `1:4`, `1:3`, `1:2`, `9:16`, `10:16`, `2:3`, `3:4`, `4:5`, `5:4`, `4:3`, `3:2`, `16:10`, `16:9`, `2:1`, `3:1`, and `4:1`. The default is `auto`.

Image to vector does not accept `size`.

## Output

A finished task returns SVG files. Each file uses `file_type: image`.

## Examples

Text to vector, text to vector with reference images, and single-image conversion are included in the OpenAPI examples.

## Notes

- Choose the model ID for the task. Text to vector does not accept `mode`. Image to vector does not accept `prompt`, `quality`, `n`, or `size`.
- On text to vector, `image_urls` are reference images. On image to vector, `image_urls` is the one image to convert.
- Keep generation parameters inside `input`. `callback_url` belongs at the top level of the request.
