<Tip>
1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.
</Tip>

Use `nano-banana-2.1` for text-to-image generation. Add `image_urls` to edit one or more reference images with the same model ID. The model supports up to 10 reference images.

## Models

- **nano-banana-2.1** - Text-to-image and image-to-image generation

The default `resolution` is `1K`. For text-to-image generation, `size` defaults to `1:1`. When `image_urls` are provided, `size` defaults to `auto`, allowing the model to choose an aspect ratio from the reference images. You can also select a supported ratio explicitly. The `auto` option is only available for image editing.
