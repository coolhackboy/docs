Anthropic Claude models cover coding, long-horizon agents, research, vision, and knowledge work. The playground on this page uses [Anthropic Messages](/api-manual/chat-series/claude-messages), which every Claude model supports.

## Models

- **claude-opus-5-5** — Claude Opus 5.5.
- **claude-sonnet-5-5** — Claude Sonnet 5.5.
- **claude-haiku-5-5** — Claude Haiku 5.5, a compact model for classification, extraction, summaries, and subagents, with a 1M-token context.
- **claude-fable-5-1** — Claude Fable 5.1, for long-horizon coding, research, and vision, with 1M context and up to 128K output.
- **claude-opus-5** — Claude Opus 5, for advanced coding, computer use, and deep research.
- **claude-sonnet-5** — Claude Sonnet 5, for agentic coding and browser or computer use, with 1M context and up to 128K output.
- **claude-opus-4-8** — Claude Opus 4.8, with 1M context and up to 128K output.
- **claude-opus-4-7** — Claude Opus 4.7, for coding, deep reasoning, and high-resolution vision.
- **claude-opus-4-6** — Claude Opus 4.6.
- **claude-sonnet-4-6** — Claude Sonnet 4.6.
- **claude-opus-4-5-20251101** — Claude Opus 4.5.
- **claude-sonnet-4-5-20250929** — Claude Sonnet 4.5.
- **claude-haiku-4-5-20251001** — Claude Haiku 4.5.

Every Claude model supports Anthropic Messages and Chat Completions.
