<Tip>
1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.
</Tip>

`gemini-3.8-flash-tts` converts a transcript or a two-speaker dialogue into native WAV speech. Results are returned as task `files`, matching the standard image, video, 3D, and audio task response structure.

## Models

- **gemini-3.8-flash-tts** - Gemini 3.8 Flash text-to-speech generation

## Required parameters

Single-speaker and dialogue inputs are mutually exclusive.

- **text**: Required for single-speaker synthesis. Non-empty transcript. Omit when using `speakers` and `turns`
- **speakers**: Required for dialogue, together with `turns`. Exactly two speakers. Each item includes:
  - `speaker_id`: Distinct non-empty speaker alias
  - `voice`: Gemini voice preset
- **turns**: Required for dialogue, together with `speakers`. At least one turn. Each item includes:
  - `speaker_id`: Must match a configured speaker
  - `text`: Non-empty turn text
  - `style_instructions`: Optional delivery direction for that turn

Dialogue requests must omit top-level `text` and top-level `voice`. The complete input is limited to 8,192 tokens.

## Optional parameters

- **voice**: Voice preset for single-speaker synthesis. Default: `Kore`. Omit for dialogue
- **style_instructions**: Global delivery style, separate from the transcript. Can be used with either mode
- **enable_safety_checker**: Enable input safety checking. Default: `true`. Disabling can require account authorization
- **callback_url**: Optional webhook URL for task completion notification

## Voice Presets

Supported values: `Achernar`, `Achird`, `Algenib`, `Algieba`, `Alnilam`, `Aoede`, `Autonoe`, `Callirrhoe`, `Charon`, `Despina`, `Enceladus`, `Erinome`, `Fenrir`, `Gacrux`, `Iapetus`, `Kore`, `Laomedeia`, `Leda`, `Orus`, `Pulcherrima`, `Puck`, `Rasalgethi`, `Sadachbia`, `Sadaltager`, `Schedar`, `Sulafat`, `Umbriel`, `Vindemiatrix`, `Zephyr`, `Zubenelgenubi`.

## Examples

### Single speaker

```json
{
  "model": "gemini-3.8-flash-tts",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "text": "Hello! Welcome to PoYo.",
    "voice": "Kore",
    "style_instructions": "Warm, confident product narrator with clear pacing."
  }
}
```

### Two-speaker dialogue

```json
{
  "model": "gemini-3.8-flash-tts",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "style_instructions": "Conversational podcast tone with distinct speaker energy.",
    "speakers": [
      {
        "speaker_id": "host",
        "voice": "Kore"
      },
      {
        "speaker_id": "guest",
        "voice": "Puck"
      }
    ],
    "turns": [
      {
        "speaker_id": "host",
        "text": "Welcome!"
      },
      {
        "speaker_id": "guest",
        "text": "Thank you.",
        "style_instructions": "Warm and friendly."
      }
    ]
  }
}
```

## Notes

- Output is native WAV. This model has no `output_format`, `temperature`, `language_code`, or `seed` parameter.
- Query status through the standard task status API.
- Successful responses return `files`. Generated speech uses `file_type: audio`. Optional timing JSON uses `file_type: other`.
