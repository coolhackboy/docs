<Tip>
1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.
</Tip>

`elevenlabs-tts-turbo-2-5` converts text inputs into low-latency multilingual speech audio. Results are returned as task `files`, matching the standard image, video, 3D, and audio task response structure.

## Models

- **elevenlabs-tts-turbo-2-5** - ElevenLabs TTS Turbo v2.5 text-to-speech generation

## Required parameters

- **text**: Text to convert to speech
  - Length: `1-40000` characters
  - Use `previous_text` and `next_text` when splitting long-form narration into multiple requests

## Optional parameters

- **voice**: Voice name or compatible voice ID for speech generation. Default: `Rachel`
- **stability**: Voice stability from `0` to `1`. Default: `0.5`
- **similarity_boost**: Voice similarity boost from `0` to `1`. Default: `0.75`
- **style**: Style exaggeration from `0` to `1`. Default: `0`
- **speed**: Speech speed from `0.7` to `1.2`. Default: `1`
- **timestamps**: Boolean. When `true`, timestamp data may be returned with the generated audio
- **previous_text**: Optional context that came before `text`, useful for long-form continuity
- **next_text**: Optional context that comes after `text`, useful for long-form continuity
- **language_code**: Optional ISO 639-1 code used to enforce a target language, such as `en`, `fr`, `de`, `ja`, `vi`, `hu`, or `no`
- **apply_text_normalization**: `auto`, `on`, or `off`. Default: `auto`

## Examples

### Low-latency product voiceover

```json
{
  "model": "elevenlabs-tts-turbo-2-5",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "text": "Welcome to NovaDesk. Your workspace is ready, your calendar is synced, and your first customer briefing starts in ten minutes.",
    "voice": "Rachel",
    "speed": 1.08,
    "stability": 0.55,
    "similarity_boost": 0.78,
    "style": 0.12,
    "timestamps": false,
    "apply_text_normalization": "auto"
  }
}
```

### Localized pickup notification

```json
{
  "model": "elevenlabs-tts-turbo-2-5",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "text": "Bonjour, votre commande est prete. Merci de presenter votre code de retrait a l'accueil.",
    "voice": "Aria",
    "language_code": "fr",
    "stability": 0.6,
    "similarity_boost": 0.75,
    "speed": 1,
    "timestamps": true,
    "apply_text_normalization": "auto"
  }
}
```

### Long-form continuity

```json
{
  "model": "elevenlabs-tts-turbo-2-5",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "previous_text": "The city lights faded behind the train.",
    "text": "Mira lowered her voice and said, keep the map close. By sunrise, everyone will be looking for it.",
    "next_text": "The carriage fell silent as the tunnel opened ahead.",
    "voice": "Sarah",
    "stability": 0.42,
    "similarity_boost": 0.82,
    "style": 0.35,
    "speed": 0.94,
    "apply_text_normalization": "auto"
  }
}
```

## Notes

- PoYo's public parameter name is `text`.
- Query status through the standard task status API.
- Successful responses return `files`, where the generated speech uses `file_type: audio`.
