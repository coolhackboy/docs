<Tip>
1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.
</Tip>

`elevenlabs-v4-tts` converts text into expressive speech audio. Results are returned as task `files`, matching the standard image, video, 3D, and audio task response structure.

## Models

- **elevenlabs-v4-tts** - ElevenLabs V4 text-to-speech generation

## Required parameters

- **text**: Text to convert to speech
  - Length: `1-5000` characters, containing non-whitespace text

## Optional parameters

- **voice**: Voice name or voice ID. Default: `Rachel`
- **stability**: Voice stability from `0` to `1`. Default: `0.5`
- **similarity_boost**: Voice similarity from `0` to `1`. Default: `0.75`
- **language_code**: Optional ISO 639-1 language code
- **apply_text_normalization**: `auto`, `on`, or `off`. Default: `auto`
- **timestamps**: Boolean. When `true`, timing data may be returned as a separate JSON file. Default: `false`
- **output_format**: Audio codec, sample rate, and bitrate. Default: `mp3_44100_128`
- **callback_url**: Optional webhook URL for task completion notification

## Output Formats

Supported values: `mp3_22050_32`, `mp3_44100_32`, `mp3_44100_64`, `mp3_44100_96`, `mp3_44100_128`, `mp3_44100_192`, `pcm_8000`, `pcm_16000`, `pcm_22050`, `pcm_24000`, `pcm_44100`, `pcm_48000`, `ulaw_8000`, `alaw_8000`, `opus_48000_32`, `opus_48000_64`, `opus_48000_96`, `opus_48000_128`, `opus_48000_192`.

MP3 and Opus are encoded audio. PCM is raw audio without a WAV header. µ-law and A-law are telephony formats. Output keeps its original encoding and file extension. Use the selected sample rate when decoding raw audio.

## Examples

### Default speech

```json
{
  "model": "elevenlabs-v4-tts",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "text": "Hello! Welcome to PoYo.",
    "voice": "Rachel",
    "stability": 0.5,
    "similarity_boost": 0.75,
    "apply_text_normalization": "auto"
  }
}
```

### Timestamps with raw PCM

```json
{
  "model": "elevenlabs-v4-tts",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "text": "Welcome to PoYo.",
    "timestamps": true,
    "output_format": "pcm_24000"
  }
}
```

## Notes

- Query status through the standard task status API.
- Successful responses return `files`. Generated speech uses `file_type: audio`.
- When `timestamps` is enabled and returned, timing JSON is a separate file item with `file_type: other`.
