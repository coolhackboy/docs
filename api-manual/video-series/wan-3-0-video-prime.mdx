# Wan 3.0 Prime Video Generation

Wan 3.0 Prime includes three models for text, start/end frame, and multimodal reference video generation.

## Models

- `wan3.0-prime-text-to-video` — generates video from a required text prompt
- `wan3.0-prime-image-to-video` — generates video from one or two start/end frame images
- `wan3.0-prime-reference-to-video` — generates video from multimodal references

## Key Features

- **Duration**: 2–30 seconds
- **Resolution**: 480p, 720p, or 1080p
- **Start/End Frames**: Use one or two `image_urls` with the image model
- **Generated Audio**: Control the output audio track with `audio`
- **Multimodal References**: Use images, videos, audio clips, documents, or public webpages with the reference model
- **Reference Labels**: Mention inputs in the prompt as `Image1`, `Video1`, or `Audio1`
