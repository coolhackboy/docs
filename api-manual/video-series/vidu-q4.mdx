Vidu Q4 animates a starting frame or uses reference images to guide the result. Reference audio can optionally accompany reference images.

## Models

- **vidu-q4** — Image-to-video and reference-to-video generation

## Features

- Generate videos from 3 to 16 seconds long.
- Animate one starting-frame image or guide a video with 1–12 reference images and up to 3 optional reference audio files.
- Choose an output resolution from 540p to 4k.
- Generate an optional audio track in reference-to-video mode.

## Input modes

- **Image-to-video**: Provide exactly one URL in `image_urls`. `prompt` is optional. Do not combine this mode with `reference_image_urls` or `reference_audio_urls`, and do not send `aspect_ratio` or `generate_audio`.
- **Reference-to-video**: Provide `prompt` and 1–12 URLs in `reference_image_urls`. `reference_audio_urls` is optional and must accompany reference images. Do not send `image_urls`.

## Required parameters

- `prompt` (string): Required for reference-to-video. Must contain 1–5,000 characters and cannot be blank.
- `image_urls` (array of strings): Required for image-to-video. Must contain exactly one starting-frame image URL.
- `reference_image_urls` (array of strings): Required for reference-to-video. Must contain 1–12 reference image URLs.

## Optional parameters

- `prompt` (string): Optional for image-to-video, with a maximum of 5,000 characters.
- `reference_audio_urls` (array of strings): Optional audio accompanying `reference_image_urls`, up to 3 files. Each file must be MP3 and 3–12 seconds long. Audio cannot be used without reference images.
- `duration` (integer): Output duration from 3 to 16 seconds. Defaults to `5`.
- `resolution` (string): `540p`, `720p`, `1080p`, `2k`, or `4k`. Defaults to `720p`.
- `aspect_ratio` (string): `16:9`, `9:16`, `4:3`, `3:4`, or `1:1`. Defaults to `16:9`. Available for reference-to-video only.
- `generate_audio` (boolean): Generate an audio track. Defaults to `false`. Available for reference-to-video only.
- `enable_safety_checker` (boolean): Enable content safety checks. Defaults to `true`.

## Examples

The request examples show animation of one starting frame with an optional prompt, and generation guided by reference images with optional audio. Both modes use the same `vidu-q4` model ID.

## Notes

- Put all generation parameters inside `input`.
- Images must use publicly accessible HTTP or HTTPS URLs.
- Reference audio must use publicly accessible HTTP or HTTPS URLs.
- Image-to-video rejects `aspect_ratio` and `generate_audio` even when `generate_audio` is `false`.
