## Capabilities

- **Text-to-Video**: Generate a video directly from a prompt.
- **Image-to-Video**: Provide one starting frame and an optional ending frame through `image_urls`.
- **Reference-to-Video**: Guide the result with reference images, videos, and audio.
- **2K Output**: The current output resolution is fixed at `2K`.

## Input Modes

- With no media input, the request uses text-to-video mode.
- `image_urls` selects image-to-video mode. It accepts one starting frame and an optional second ending frame.
- Any of `reference_image_urls`, `reference_video_urls`, or `reference_audio_urls` selects reference-to-video mode.
- `image_urls` cannot be combined with any `reference_*_urls` field.
- Reference images, videos, and audio can be combined in one reference-to-video request.
- Reference audio cannot be the only reference input. Include at least one reference image or reference video.

## Parameter Notes

- `prompt` is required.
- `duration` accepts an integer from `5` through `15` seconds and defaults to `5`.
- `resolution` currently accepts only `2K`.
- Text-to-video supports `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, and `9:16`. Its default is `16:9`.
- Reference-to-video supports the same fixed aspect ratios plus `adaptive`. Its default is `adaptive`.
- Image-to-video follows the aspect ratio of the first image, so `aspect_ratio` is not accepted in that mode.
- `reference_image_urls` accepts up to 9 images.
- `reference_video_urls` accepts up to 3 video clips. Each clip should be 2–15 seconds, with a combined duration of at most 15 seconds.
- `reference_audio_urls` accepts up to 3 audio clips. Each clip should be 2–15 seconds, with a combined duration of at most 15 seconds.
- Mention reference assets in the prompt by modality and order, such as `Image 1`, `Video 1`, and `Audio 1`.
- All media URLs must be publicly accessible and directly downloadable.

## Billing

Video generation is billed by duration. When reference videos are used, their input duration is also included in duration-based billing.
