OmniHuman 2.0 creates an audio-driven character video from one image and a driving audio file. Use an optional prompt to guide the character's motion and performance.

## Models

- **omnihuman-2.0** — Audio-driven character animation

## Features

- Animate one character image with a driving audio track.
- Guide motion and performance with an optional text prompt.

## Required parameters

- `image_urls` (array of strings): Exactly one character image URL.
- `audio_url` (string): Driving audio URL. Audio must be 4–300 seconds long and no larger than 15 MB.

## Optional parameters

- `prompt` (string): Optional instructions for motion and performance.

## Examples

The request example uses only the required `image_urls` and `audio_url` fields. Add `prompt` inside `input` when performance instructions are needed.

## Notes

- Put all generation parameters inside `input`.
- Images must use publicly accessible HTTP or HTTPS URLs.
- `audio_url` must be a publicly accessible HTTP or HTTPS URL.
- A separate `duration` parameter is not accepted; the driving audio determines the requested performance length.
