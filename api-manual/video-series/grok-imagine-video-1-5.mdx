# Grok Imagine Video 1.5

Use `grok-imagine-video-1.5` for three generation modes with 1–15 second outputs:

- **Text to video**: omit both image fields. Supports 480p, 720p, and 1080p.
- **Image to video**: provide exactly one item in `image_urls` as the first frame. Supports 480p, 720p, and 1080p.
- **Reference to video**: provide 1–7 items in `reference_image_urls`. Reference them in the prompt as `<IMAGE_0>`, `<IMAGE_1>`, and so on. Supports 480p and 720p.

`image_urls` and `reference_image_urls` cannot be used together.

## Parameters

- **prompt** (required): up to 4,096 characters.
- **image_urls**: exactly one first-frame image for image-to-video.
- **reference_image_urls**: 1–7 reference images for character, subject, or style consistency.
- **resolution**: `480p`, `720p`, or `1080p`. Reference-to-video does not support `1080p`. Default: `720p`.
- **duration**: integer from `1` to `15`. Default: `6` for text/image mode and `8` for reference mode.
- **aspect_ratio**: `16:9`, `4:3`, `3:2`, `1:1`, `2:3`, `3:4`, or `9:16`. Available only for text and reference modes; default: `16:9`.
- **callback_url**: optional completion webhook URL.

## Billing

Billing depends on the selected resolution, output duration, and number of input images. See the [Grok Imagine Video 1.5 model page](https://poyo.ai/models/grok-imagine-video-1-5) for current pricing.

Use public HTTPS image URLs or upload images through the playground before submitting.
