Every video model is called through `POST /api/generate/submit`. Send a model ID in `model`, the model's parameters in `input`, and an optional `callback_url`. The request returns a `task_id` right away and the task runs asynchronously.

## Workflow

1. Submit a task to `POST /api/generate/submit` with a model ID from the table below.
2. Poll [Get Task Status](/api-manual/task-management/video-status) with the returned `task_id`, or receive the result at `callback_url` (see [Webhook Callbacks](/api-manual/task-management/video-webhooks)).
3. Download the files in `files` when the status is `finished`.

Some models expose one model ID per mode, such as text-to-video, image-to-video, or reference-to-video. Others use a single ID and choose the mode from the inputs you send; see each model page.

## Notes

- Each model page lists the parameters, limits, and modes for its model IDs. Parameters are not shared across models.
- Generated video files are accessible for 3 days after creation. Download and store them promptly.
- URL inputs must be publicly accessible HTTP(S) URLs. To use local files, upload them first with [File Management](/api-manual/file-series/upload-url).
