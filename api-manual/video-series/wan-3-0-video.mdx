<Tip>
1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.
</Tip>

Wan 3.0 includes three models for text, start/end frame, and multimodal reference video generation.

## Models

- `wan3.0-text-to-video` — generates video from a required text prompt
- `wan3.0-image-to-video` — generates video from one or two start/end frame images
- `wan3.0-reference-to-video` — generates video from multimodal references

## Features

- **Duration**: 2–30 seconds
- **Resolution**: 480p, 720p, or 1080p
- **Start/End Frames**: Use one or two `image_urls` with the image model
- **Generated Audio**: Control the output audio track with `audio`
- **Multimodal References**: Use images, videos, audio clips, documents, or public webpages with the reference model
- **Reference Labels**: Mention inputs in the prompt as `Image1`, `Video1`, or `Audio1`
