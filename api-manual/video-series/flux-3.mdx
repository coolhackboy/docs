<Tip>
1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.
</Tip>

Select a model based on the source media you want to provide:

| Model | Required media input |
| --- | --- |
| `flux-3/text-to-video` | None |
| `flux-3/image-to-video` | One image in `image_urls` |
| `flux-3/first-last-frame-to-video` | Two ordered images in `image_urls` |
| `flux-3/extend-video` | One MP4 in `video_url` |
| `flux-3/keyframes-to-video` | 1-10 items in `keyframes` |

See the parameter descriptions below for model-specific requirements and limits.
