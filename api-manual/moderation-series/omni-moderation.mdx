**Price: FREE (0 credits)**

Omni Moderation reviews text, at most one HTTPS image, or both using OpenAI `omni-moderation-latest`. Submit a review through the unified generation endpoint, then poll [Get Task Status](/api-manual/task-management/status) with the returned `task_id` or receive an optional callback.

Submission immediately returns `status: "not_started"`. The review runs asynchronously and moves through `running` to `finished` or `failed`.

<Info>
Callbacks are supported through the optional outer `callback_url` field. Streaming is not supported; do not send `stream`.
</Info>

## Input

| Field | Type | Description |
|-------|------|-------------|
| `model` | string | Must be `omni-moderation-latest` |
| `callback_url` | string (URI) | Optional webhook URL for task completion or failure |
| `input.prompt` | string | Optional text to review; may accompany one image |
| `input.image_urls` | string[] | Optional array containing at most one HTTPS image URL |

**At least one of `prompt` or `image_urls` is required; both may be provided.** Use non-whitespace text, one HTTPS image URL, or both. `image_urls` remains an array and accepts at most one image. Submit multiple images as separate tasks. Empty input is rejected.

## Submit a Review

```bash
curl -X POST https://api.poyo.ai/api/generate/submit \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "omni-moderation-latest",
    "input": {
      "prompt": "A peaceful mountain landscape."
    }
  }'
```

To review an image together with text:

```json
{
  "model": "omni-moderation-latest",
  "input": {
    "prompt": "A mountain view at sunset.",
    "image_urls": [
      "https://example.com/image.jpg"
    ]
  }
}
```

For image-only review, omit `prompt`. To receive the completed task through a webhook, provide `callback_url` outside `input`:

```json
{
  "model": "omni-moderation-latest",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "prompt": "A peaceful mountain landscape."
  }
}
```

### Submit Response

```json
{
  "code": 200,
  "data": {
    "task_id": "MODERATION_TASK_ID",
    "status": "not_started",
    "created_time": "2026-10-14T10:00:00"
  }
}
```

## Retrieve the Result

```bash
curl https://api.poyo.ai/api/generate/status/MODERATION_TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Poll until `data.status` becomes `finished` or `failed`. A completed review returns the full OpenAI response in `data.output`; `data.files` is empty and `data.credits_amount` is `0`.

| Field | Type | Description |
|-------|------|-------------|
| `data.output.id` | string | OpenAI moderation response identifier |
| `data.output.model` | string | Model identifier returned by OpenAI, which may be a dated model version |
| `data.output.results` | array | OpenAI review results |
| `data.output.results[].flagged` | boolean | Whether OpenAI flagged the reviewed content |
| `data.output.results[].categories` | object | Classification booleans by category |
| `data.output.results[].category_scores` | object | Confidence scores by category |
| `data.output.results[].category_applied_input_types` | object | Input modalities used for each category |

`status: "finished"` means that the review completed. A result with `flagged: true` is a successful review that detected content, and does not make the task `failed`. Check `data.error_message` only when the task itself fails.

## Callback Body

When `callback_url` is provided, PoYo sends a POST request when the task becomes `finished` or `failed`. The body is the status response's `data` object, without the outer `code` and `data` wrapper. It includes `task_id`, `status`, `credits_amount: 0`, `files: []`, and the completed OpenAI response in `output` when available. Failed tasks expose `error_message`.

See [Webhook Callbacks](/api-manual/task-management/webhooks) for signature verification.
