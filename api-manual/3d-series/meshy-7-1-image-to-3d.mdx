Submission returns a `task_id`. Use [Query Task Status](/api-manual/task-management/status) to track completion, or supply `callback_url` for completion and failure notifications.

## Parameters and combinations

`image_urls` requires exactly one image.

`model_type` accepts `standard` (default), `lowpoly`, or `smart-topology`. Optional `geometry_resolution` accepts `standard`, `2k`, or `4k`.

`topology` accepts `triangle` (default) or `quad`. `target_polycount` accepts 100–300,000 and defaults to 30,000; Smart Topology defaults to 4,000 and allows at most 15,000. Remesh controls are ignored in lowpoly mode.

`should_remesh` defaults to `true`; `symmetry_mode` accepts `off`, `auto` (default), or `on`; `pose_mode` accepts an empty string (default), `a-pose`, or `t-pose`.

`enable_pbr` defaults to `false`. Optional texture guidance uses `texture_prompt` (at most 600 characters) or `texture_image_url`. `should_texture` defaults to `true`.

`enable_rigging` and `enable_animation` default to `false`. Animation requires `enable_rigging=true`. `rigging_height_meters` must be positive (default 1.7); `animation_action_id` accepts 0–696 (default 92).

`enable_safety_checker` defaults to `true`. Optional features can change the task price; inspect the live Catalog before submitting.

## Examples

```json
{
  "model": "meshy-7.1-image-to-3d",
  "input": {
    "image_urls": [
      "https://example.com/front.png"
    ],
    "enable_rigging": true,
    "enable_animation": true
  }
}
```

## Task results

The query response uses the common task structure: `task_id`, `status`, `progress`, `files`, and `error_message`. A finished task has `status="finished"`; each result file has `file_url` and `file_type`. Preserve the task ID while polling.

3D assets appear as `file_type="3d"`, with thumbnails and textures as images. Rigged meshes and animation assets are returned when requested and available.
