Every 3D model is called through `POST /api/generate/submit`. Send a model ID in `model`, the model's parameters in `input`, and an optional `callback_url`. The request returns a `task_id` right away and the task runs asynchronously.

## Workflow

1. Submit a task to `POST /api/generate/submit` with a model ID from the table below.
2. Poll [Get Task Status](/api-manual/task-management/3d-status) with the returned `task_id`, or receive the result at `callback_url` (see [Webhook Callbacks](/api-manual/task-management/3d-webhooks)).
3. Download the files in `files` when the status is `finished`.

Each 3D model exposes one model ID per input mode, such as text-to-3D, image-to-3D, or multi-image-to-3D.

## Notes

- Each model page lists the parameters, limits, and modes for its model IDs. Parameters are not shared across models.
- Generated 3D files are accessible for 3 days after creation. Download and store them promptly.
- URL inputs must be publicly accessible HTTP(S) URLs. To use local files, upload them first with [File Management](/api-manual/file-series/upload-url).
