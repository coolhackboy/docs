<Tip>
1. After submission, a `task_id` will be returned. If you provided a `callback_url`, when the task status becomes `finished` or `failed`, a POST request will be sent to the `callback_url`.
2. Regardless of whether `callback_url` is provided, you can retrieve the result through the unified [Query Task Status](/api-manual/task-management/status) endpoint.
</Tip>

Meshy 7.1 supports text-to-3D, single image-to-3D, and multi-image-to-3D generation through three public model IDs. Optional textures, rigging, and animation can be requested on the same task.

## Models

- **meshy-7.1-text-to-3d** - Generate a 3D model from a prompt
- **meshy-7.1-image-to-3d** - Generate a 3D model from one image
- **meshy-7.1-multi-image-to-3d** - Generate a 3D model from 1-4 images of the same object

## Required parameters

- **model**: `meshy-7.1-text-to-3d`, `meshy-7.1-image-to-3d`, or `meshy-7.1-multi-image-to-3d`
- **input.prompt**: Required for `meshy-7.1-text-to-3d`. Use `1-600` characters containing non-whitespace text. Omit for image models
- **input.image_urls**: Required for image models. Use exactly 1 image for `meshy-7.1-image-to-3d`, and 1-4 images for `meshy-7.1-multi-image-to-3d`. Omit for text-to-3D

Image inputs and `texture_image_url` accept public HTTP(S) image URLs or image data URIs.

## Optional parameters

- **mode**: Text-to-3D only. `preview` returns geometry only; `full` includes textures. Default is `full`
- **model_type**: Text-to-3D and single image-to-3D only. `standard` or `smart-topology`. Default is `standard`. Omit for multi-image generation. Lowpoly is not supported
- **geometry_resolution**: `standard`, `2k`, or `4k` for text-to-3D and single image-to-3D when `model_type` is `standard`. Omit when `model_type` is `smart-topology`. Multi-image generation accepts only `standard` or `2k`
- **topology**: `triangle` or `quad`. Default is `triangle`
- **target_polycount**: Target polygon count from `100` to `300000`. Default is `30000`. For text-to-3D and single image-to-3D with `model_type=smart-topology`, the range is `100-15000` and the default is `4000` when omitted
- **should_remesh**: Whether to enable remeshing. Default is `true`
- **symmetry_mode**: `off`, `auto`, or `on`. Default is `auto`
- **should_texture**: Image models only. Whether to generate textures. Default is `true`. For multi-image generation, this must remain `true` when `enable_pbr` is `true` or texture guidance is supplied
- **enable_pbr**: Generate PBR maps such as metallic, roughness, and normal maps. Default is `false`. Multi-image generation requires `should_texture=true`
- **pose_mode**: `a-pose`, `t-pose`, or an empty string for no specific pose
- **seed**: Text-to-3D only. Integer seed. Omit to select a seed automatically
- **enable_prompt_expansion**: Text-to-3D only. Whether to expand the prompt before generation. Default is `false`
- **texture_prompt**: Optional texture guidance, at most `600` characters. Multi-image generation requires `should_texture=true`
- **texture_image_url**: Optional texture guidance image. Multi-image generation requires `should_texture=true`
- **enable_rigging**: Whether to rig a humanoid character. Default is `false`. Must be `true` when `enable_animation` is `true`
- **rigging_height_meters**: Character height in meters when rigging is enabled. Must be greater than zero. Default is `1.7`
- **enable_animation**: Whether to apply an animation preset. Requires `enable_rigging=true`. Default is `false`
- **animation_action_id**: Animation preset ID from `0` to `696`. Default is `92`
- **enable_safety_checker**: Whether to enable input safety checking. Default is `true`. Disabling can require account authorization
- **callback_url**: Optional webhook URL for task completion notification

## Output

The task result is returned as a file list. Available items may include:

- 3D assets with `file_type: 3d`
- thumbnails and textures as images
- rigged meshes and animation assets when those options are enabled and the files are available

Each file item includes `file_url` and `file_type`.

## Examples

### Text to 3D with rigging and animation

```json
{
  "model": "meshy-7.1-text-to-3d",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "prompt": "A ceramic robot with a clean silhouette.",
    "enable_rigging": true,
    "enable_animation": true
  }
}
```

### Text to 3D with Smart Topology preview

```json
{
  "model": "meshy-7.1-text-to-3d",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "prompt": "A ceramic robot.",
    "mode": "preview",
    "model_type": "smart-topology"
  }
}
```

### Single image to 3D

```json
{
  "model": "meshy-7.1-image-to-3d",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "image_urls": [
      "https://example.com/front.png"
    ],
    "enable_rigging": true,
    "enable_animation": true
  }
}
```

### Multiple images to 3D

```json
{
  "model": "meshy-7.1-multi-image-to-3d",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "image_urls": [
      "https://example.com/front.png",
      "https://example.com/back.png"
    ],
    "enable_rigging": true,
    "enable_animation": true
  }
}
```

## Notes

- `meshy-7.1-image-to-3d` accepts exactly one image in `image_urls`.
- `meshy-7.1-multi-image-to-3d` accepts 1-4 images. Images should show the same object from different angles.
- The API returns asynchronous task status. Poll the unified task status endpoint or use `callback_url`.
