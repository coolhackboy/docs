Video Upscaler increases the resolution of an existing video. The output size is the input size multiplied by `scale`.

## Models

- **poyo-ai/video-upscaler** — Upscale one video

## Required parameters

- `video_url` (string): Source video URL.

## Optional parameters

- `scale` (number): Upscale factor from `1` to `8`. Default is `2`. Decimals are allowed.

## Output

A finished task returns one upscaled video in `files` with `file_type: video`.

## Examples

- **Upscale a video 2x** — sets `video_url`, `scale`.

## Notes

- PoYo reads the source width, height, duration, and frame rate before submitting. Submission fails if the file has no readable video stream.
