# Connect Claude

Claude Code can connect directly to hosted PoYo MCP. Claude Desktop can use the local stdio bridge.

## Claude Code

Set `POYO_API_KEY`, then run:

```bash
claude mcp add --transport http poyo \
  https://api.poyo.ai/mcp \
  --header "Authorization: Bearer $POYO_API_KEY"
```

## Claude Desktop

Node.js 20 or later is required. Add this server to the Claude Desktop developer configuration, then restart Claude:

```json
{
  "mcpServers": {
    "poyo": {
      "command": "npx",
      "args": ["-y", "@poyoapi/mcp"],
      "env": { "POYO_API_KEY": "YOUR_API_KEY" }
    }
  }
}
```

<Warning>
  This local configuration contains a credential. Do not commit or share it.
</Warning>

On native Windows, Claude Code can also use the stdio bridge:

```powershell
$env:POYO_API_KEY="YOUR_API_KEY"
claude mcp add poyo --scope user -- cmd /c npx -y @poyoapi/mcp
```
