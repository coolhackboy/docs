# Choose MCP Tools

The default [PoYo MCP endpoint](/integrations/mcp) exposes a compact tool set for discovering models, checking schemas and pricing, and executing work. In most cases, start there.

## Use typed tools

Add a filter when an integration benefits from model-specific tool names and JSON Schemas:

```text
https://api.poyo.ai/mcp?models=flux-schnell,tripo3d-h3.1-text-to-3d
```

Typed mode exposes tools such as `poyo_flux_dev`. Their input schemas come directly from the live Capability Catalog. `poyo_check_job` and `poyo_account` remain available.

## Choose a filter

| Filter | Use it when | Tradeoff |
|---|---|---|
| `models=MODEL_A,MODEL_B` | The integration needs a stable, reviewed model set | Requires updating the URL to add models |
| `categories=image,video` | Users need to explore a changing category | The tool set can grow as the catalog changes |

<Warning>
  Do not combine `models` and `categories` in one URL.
</Warning>

## Limits

- Select at most 20 explicit models.
- Select at most 3 categories.
- The expanded endpoint may expose at most 30 model tools.
- Restart the MCP server or client after changing filters so it refreshes the tool list.

Prefer explicit model IDs for production integrations. Use category filters for exploration, and switch to model IDs once the set should remain predictable.
