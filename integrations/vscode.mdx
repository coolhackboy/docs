# Connect VS Code

Run **MCP: Open User Configuration** and add PoYo to `mcp.json`:

```json
{
  "servers": {
    "poyo": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@poyoapi/mcp"],
      "env": {
        "POYO_API_KEY": "${input:poyo-api-key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "poyo-api-key",
      "description": "PoYo API key",
      "password": true
    }
  ]
}
```

VS Code prompts for the key when the server starts, so it does not need to be stored in the file. Node.js 20 or later is required for the stdio bridge.

## Verify

Start or restart `poyo` from **MCP: List Servers**, then ask: `Use PoYo to check my account and list image-generation models.`

For typed model tools and usage examples, see [PoYo MCP](/integrations/mcp).
