# AI agents and developer tools

Choose a path based on how you want to work. All options use the same Capability Catalog, authentication, asynchronous tasks, and normalized results as the REST API.

| I want to... | Recommended path | Start here |
|---|---|---|
| Ask a coding agent (Claude Code, Codex, Cursor) to pick and run models | Agent Skill + CLI | [Quickstart](/integrations/quickstart) |
| Give an AI client PoYo tools it can call directly | MCP (optionally + Agent Skill) | [MCP quickstart](/integrations/mcp) |
| Run model calls from a terminal or CI | CLI | [CLI](/integrations/cli) |
| Build an application with HTTP requests | REST API | [API overview](/api-manual/overview) |
| Add PoYo to no-code automations | n8n community node | [n8n](/integrations/n8n) |
| Use PoYo models on a visual node canvas | ComfyUI custom nodes | [ComfyUI](/integrations/comfyui) |

The Agent Skill works with either MCP or the CLI. If MCP is not connected, it runs models through `npx @poyoapi/cli`.

## Fastest path

For Claude Code, Codex, or Cursor, no MCP setup is needed:

```bash
npx -y @poyoapi/cli auth login
npx skills add PoyoAPI/poyo-devtools --skill poyo-ai-models --agent claude-code --yes
```

Then reopen the agent and ask it to generate an image with PoYo. See the [Quickstart](/integrations/quickstart) for each client, verification, and an example prompt. To give your client PoYo tools directly, see [MCP quickstart](/integrations/mcp).

## Integration summary

| Integration | Best for | Install or URL | Availability |
|---|---|---|---|
| Agent Skill | Model selection, cost control, and task workflow for coding agents | `npx skills add PoyoAPI/poyo-devtools --skill poyo-ai-models` | Repository install |
| CLI | Shell scripts, CI, and Skill execution without MCP | `npx -y @poyoapi/cli` (optional: `npm install -g @poyoapi/cli`) | Available |
| Remote MCP | Hosted AI clients | `https://api.poyo.ai/mcp` | Available |
| stdio MCP | Local-only MCP clients | `npx -y @poyoapi/mcp` | Available |

<Info>
  CLI and stdio MCP are local clients, not separately deployed services. The hosted MCP endpoint runs alongside the PoYo API.
</Info>
