## Choose an interface

| Requirement | Recommended interface |
|---|---|
| Integrate a product directly | REST API |
| Stream chat tokens | REST API or `poyo chat --stream` |
| Let an AI agent choose and run a model | Hosted MCP |
| MCP host only supports stdio | `npx @poyo/mcp` |
| Automate from a shell or CI job | `npx @poyo/cli` |
| Give an agent PoYo operating guidance | `poyo-ai-models` Skill |

## Start in three commands

```bash
npx -y @poyo/cli auth login
npx -y @poyo/cli models image
npx -y @poyo/cli describe MODEL_ID
```

After reviewing the schema and price, run the model:

```bash
npx -y @poyo/cli run MODEL_ID --input '{"prompt":"A cinematic sunrise over Shanghai"}'
```

<Info>
  A generation may finish immediately or return a task ID. Keep the ID and retrieve the existing task instead of submitting the same paid work again.
</Info>

## The workflow is always the same

<Steps>
  <Step title="Search">
    Find a model by service type, category, tags, or free-text query.
  </Step>
  <Step title="Describe">
    Read the current input schema, output schema, protocols, and pricing.
  </Step>
  <Step title="Execute">
    Use non-streaming MCP chat, CLI streaming chat, or asynchronous generation.
  </Step>
  <Step title="Retrieve">
    Poll generation tasks until they reach `succeeded` or `failed`.
  </Step>
</Steps>

## Shared source of truth

The production Capability Catalog drives MCP tool definitions, CLI parameter discovery, generated Skill references, and machine-readable API documentation. Do not hard-code a model schema from an old response.

## Authentication

Use the same PoYo API key for REST, MCP, and CLI:

```bash
Authorization: Bearer YOUR_API_KEY
```

Never place an API key in an MCP URL, prompt, committed file, or retained shell command.
