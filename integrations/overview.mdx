# AI and developer integrations

Choose an integration based on how you want to work. All options use the same Capability Catalog, authentication, public pricing, asynchronous tasks, and normalized results as the REST API.

| I want to... | Recommended integration | Start here |
|---|---|---|
| Ask an AI client to discover and run models | MCP | [MCP quickstart](/integrations/mcp) |
| Teach an agent model selection, cost control, and execution workflows | MCP + Agent Skill | [Agent Skill](/integrations/skill) |
| Run model calls from a terminal or CI | CLI | [CLI](/integrations/cli) |
| Build an application with HTTP requests | REST API | [API overview](/api-manual/overview) |

## Fastest path

For most AI-client users:

1. Set `POYO_API_KEY`.
2. Connect to `https://api.poyo.ai/mcp`, or run `npx -y @poyoapi/mcp` for a stdio-only client.
3. Ask the client to check your account, select a model, show its price, run it, and wait for the returned task.

```text
Use PoYo to check my account, find a suitable image model, and show me its
price. Generate a cinematic product photo, wait for the task to finish, then
return the output URL.
```

See [MCP quickstart](/integrations/mcp) for client configuration, available tools, task polling, and result handling.

## Integration summary

| Integration | Best for | Install or URL | Availability |
|---|---|---|---|
| Remote MCP | Hosted AI clients | `https://api.poyo.ai/mcp` | Available |
| stdio MCP | Local-only MCP clients | `npx -y @poyoapi/mcp` | Available |
| CLI | Shell scripts and model execution | `npm install -g @poyoapi/cli` | Available |
| Agent Skill | Reusable model workflow | `npx skills add PoyoAPI/poyo-devtools` | Repository install |

<Info>
  CLI and stdio MCP are local clients, not separately deployed services. The hosted MCP endpoint runs alongside the PoYo API.
</Info>
