# PoYo Integrations

Give Claude, Cursor, Codex, VS Code, and other AI assistants live access to PoYo model discovery, schemas, pricing, and execution.

## Connect with MCP

PoYo hosts a Streamable HTTP MCP server at:

```text
https://api.poyo.ai/mcp
```

Public model discovery works without authentication. Add a [PoYo API key](/integrations/authentication) as a Bearer token to access account information and run models. Configuring the key when you connect gives your assistant the complete workflow without relying on stale model knowledge.

## Choose another interface

| If you want to... | Use |
|---|---|
| Let an AI assistant find and run models | [MCP](/integrations/mcp) |
| Automate model calls from a terminal or CI | [PoYo CLI](/integrations/cli) |
| Add repeatable PoYo guidance to a coding agent | [PoYo Agent Skill](/integrations/skill) |
| Integrate models directly into an application | [REST API](/api-manual/overview) |
| Compare streaming, tool calls, and async tasks | [Execution methods](/integrations/execution-methods) |

<Info>
  MCP is designed for agent-driven work. For application traffic or token-by-token chat output, use the REST API directly.
</Info>

## Use the same live model data

MCP, CLI, Agent Skill, and REST integrations share the [Capability Catalog](/integrations/catalog), model schemas, public pricing, authentication, and task lifecycle. Always inspect the current schema before execution instead of hard-coding parameters from an old response.
