# Cursor

The stdio bridge is the most portable Cursor configuration and does not require a separate OAuth flow.

## Configure

Open Cursor's MCP settings and add:

```json
{
  "mcpServers": {
    "poyo": {
      "command": "npx",
      "args": ["-y", "@poyoapi/mcp"],
      "env": {
        "POYO_API_KEY": "YOUR_API_KEY"
      }
    }
  }
}
```

Restart the MCP server after saving so Cursor refreshes the tool list.

<Warning>
  Do not commit or share a configuration containing your API key.
</Warning>

## Typed tools

To expose typed image and 3D model tools:

```json
"args": ["-y", "@poyoapi/mcp", "--models", "flux-schnell,tripo3d-h3.1-text-to-3d"]
```

Explicit model IDs keep the tool set predictable as categories grow. See [Choose MCP tools](/integrations/mcp-filtering) for filtering limits.

## Verify

Ask Cursor:

```text
Use PoYo to search for image models, inspect the selected model's schema
and pricing, then tell me which execution tool you would use.
```
