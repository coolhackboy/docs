# Connect Cursor

Add PoYo to Cursor's MCP configuration, then restart the MCP server so Cursor refreshes its tools.

```json
{
  "mcpServers": {
    "poyo": {
      "url": "https://api.poyo.ai/mcp",
      "headers": {
        "Authorization": "Bearer ${env:POYO_API_KEY}"
      }
    }
  }
}
```

If your Cursor version does not support authenticated remote servers, use the stdio bridge:

```json
{
  "mcpServers": {
    "poyo": {
      "command": "npx",
      "args": ["-y", "@poyoapi/mcp"],
      "env": { "POYO_API_KEY": "YOUR_API_KEY" }
    }
  }
}
```

<Warning>
  Keep the API key in an environment variable when possible. Do not commit a configuration containing it.
</Warning>

`${env:POYO_API_KEY}` reads the environment Cursor was started with. A variable set with `export` or `$env:` in a terminal applies only to that session, so Cursor launched from the desktop does not see it.

To use Cursor without MCP, follow the [Quickstart](/integrations/quickstart) with `--agent cursor`.

## Verify

Ask Cursor: `Use PoYo to find image models, inspect one model's schema, and show its price. Do not run it.`

For typed model tools and usage examples, see [PoYo MCP](/integrations/mcp).
