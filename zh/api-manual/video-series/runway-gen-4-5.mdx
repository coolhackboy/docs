<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

`runway-gen-4.5` 通过统一的提交接口提供，支持文生视频，并可选用单张图片引导。

## 模型

- **runway-gen-4.5** - 文生视频

## 必填参数

- **prompt**：用于生成的文本提示词

## 可选参数

- **duration**：`5` 或 `10`。默认为 `5`
- **aspect_ratio**：`16:9`、`9:16`、`4:3`、`3:4`、`1:1` 或 `21:9`。默认为 `16:9`
- **image_urls**：可选的图片 URL 列表。最多 `1` 张图片
- **seed**：可选的整数随机种子

## 注意事项

- `image_urls` 为可选。如果提供，只允许一个图片 URL
