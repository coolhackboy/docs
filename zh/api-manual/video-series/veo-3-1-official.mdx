通过 PoYo 的官方模型系列生成 VEO 3.1 视频。根据所选模型，生成模型支持文生视频、图生视频、首尾帧视频，以及由 `generation_type` 驱动的三图生成。

## 模型

- **veo3.1-fast-official** - 快速官方生成，时长可选 4、6 或 8 秒
- **veo3.1-lite-official** - 轻量官方生成
- **veo3.1-quality-official** - 更高质量的官方生成，支持 4K

## 输入模式

### 生成模型

- 不传 `image_urls`：文生视频
- 一张图片：图生视频
- 两张图片：首尾帧视频；`veo3.1-lite-official` 仅在 8 秒时支持此模式
- 三张图片：`generation_type: "reference"`，时长固定为 8 秒
- `veo3.1-lite-official` 最多支持两张图片，不支持 `generation_type: "reference"`

## 必填参数

- **prompt**：必填的文本提示词

## 可选参数

- **image_urls**：生成模型可选的图片 URL 数组
- **generation_type**：可选，`frame` 或 `reference`；如果省略，PoYo 会根据 `image_urls` 推断模式；`veo3.1-lite-official` 传两张图片时仍需 `duration: 8`
- **duration**：生成模型支持 `4`、`6` 或 `8`；`generation_type: "reference"` 搭配三个 `image_urls` 时仅支持 `8`；`veo3.1-lite-official` 搭配两个 `image_urls` 时仅支持 `8`；`veo3.1-lite-official` 搭配 `resolution: "1080p"` 时仅支持 `8`
- **aspect_ratio**：`16:9` 或 `9:16`；图生视频和首尾帧生成还支持 `auto`
- **resolution**：在支持的模型上可选 `720p`、`1080p` 或 `4k`；`veo3.1-lite-official` 不支持 `4k`
- **sound**：默认为 `true`；设为 `false` 输出无声视频
