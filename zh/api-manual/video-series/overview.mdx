所有视频模型都通过 `POST /api/generate/submit` 调用。在 `model` 中传入 model ID，在 `input` 中传入该模型的参数，并可选传入 `callback_url`。请求会立即返回 `task_id`，任务异步执行。

## 工作流程

1. 使用下表中的 model ID 向 `POST /api/generate/submit` 提交任务。
2. 使用返回的 `task_id` 轮询[获取任务状态](/zh/api-manual/task-management/video-status)，或在 `callback_url` 接收结果（参见 [Webhook 回调](/zh/api-manual/task-management/video-webhooks)）。
3. 状态为 `finished` 时，下载 `files` 中的文件。

部分模型为每种模式提供一个 model ID，例如文生视频、图生视频或参考生视频。其他模型使用单一 ID，并根据你传入的输入选择模式；详见各模型页面。

## 注意事项

- 每个模型页面列出其 model ID 的参数、限制和模式。参数不在模型之间通用。
- 生成的视频文件在创建后 3 天内可访问。请及时下载并保存。
- URL 输入必须是可公开访问的 HTTP(S) URL。如需使用本地文件，请先通过[文件管理](/zh/api-manual/file-series/upload-url)上传。
