Kling 4.0 Flash 是 [Kling 4.0](/zh/api-manual/video-series/kling-4-0) 的快速 720p 版本，可根据文本创建视频、让起始帧动起来、组合视觉参考，或编辑已有视频。模式由提供的媒体自动选择。

## 模型

- **kling-4.0-flash** — `720p` 文生视频、图生视频、参考生视频和视频编辑

## 功能

- **快速 720p 输出**：生成 3–20 秒的 `720p` 视频。
- **起始帧**：让一张起始图片动起来。Flash 不支持结束帧。
- **视觉参考**：通过参考图片、参考视频以及由图片或视频定义的主体来引导外观和动作。
- **视频编辑**：提供源视频并描述要做的修改，编辑时还可以加入参考图片、参考视频和主体。不传 `duration` 即保留源视频时长。
- **宽高比**：文本模式和参考模式可使用 `16:9`、`9:16`、`1:1`、`21:9` 或 `auto`。

## 输入模式

| 模式 | 选择条件 |
| --- | --- |
| 视频编辑 | 提供了 `video_url` |
| 参考生视频 | 参考图片、参考视频或 `kling_elements` 非空 |
| 图生视频 | `image_urls` 非空且没有参考素材 |
| 文生视频 | 未提供任何媒体 |

在参考模式下，`image_urls` 可包含一个可选的起始帧。在图片模式下，`prompt` 可选；不要传 `aspect_ratio`。编辑模式不接受 `image_urls` 或 `aspect_ratio`。

## 必填参数

- `prompt` (string)：视频指令，1–26,000 个字符，至少包含一个非空白字符。除图生视频可选外，其余模式均必填。

## 可选参数

- `duration` (integer)：输出时长，3 到 20 秒。生成模式默认为 `5`。在编辑模式下，不传该字段即保留源视频时长；计费输出时长向上取整到整秒。
- `resolution` (string)：仅支持 `720p`。默认：`720p`。
- `aspect_ratio` (string)：`auto`、`16:9`、`9:16`、`1:1` 或 `21:9`，用于文本模式和参考模式。默认：`16:9`。文生视频中 `auto` 按 `16:9` 处理；参考模式中 `auto` 会适配所提供的素材。图片模式和编辑模式下不要传该字段。
- `image_urls` (array of strings)：一张起始图片。
- `video_url` (string)：用于编辑的源视频。时长必须为 3–20 秒。
- `reference_image_urls` (array of strings)：最多 10 个可公开访问的 HTTP 或 HTTPS 图片 URL。
- `reference_video_urls` (array of strings)：可公开访问的 HTTP 或 HTTPS 视频 URL，每个时长 3–20 秒。参考模式最多 5 个，编辑模式最多 4 个。
- `kling_elements` (array of objects)：最多 7 个主体。每个主体只能提供以下其中一项：
  - `element_input_urls` (array of strings)：2–4 张图片，正面视图在前，其他参考视图在后。
  - `element_input_video_urls` (array of strings)：恰好一个 3–8 秒的视频。最多 3 个主体可以使用视频。

主体按其在数组中的位置识别，无需命名。以 `@Element1`、`@Element2` 等引用它们。参考图片使用 `@Image1`、`@Image2` 等。参考模式下参考视频从 `@Video1` 开始；编辑模式下源视频为 `@Video1`，参考视频从 `@Video2` 开始。现有的 `@image_1` 和 `@video_1` 引用仍然支持。

## 示例

- **文生视频**：发送不带参考素材的 `prompt`。仅在需要时设置 `duration` 或 `aspect_ratio`。
- **图生视频**：在 `image_urls` 中放一张起始图片，可选附带 `prompt`。
- **视觉参考**：组合使用 `reference_image_urls`、`reference_video_urls` 或 `kling_elements`，并按位置引用它们。
- **视频编辑**：提供 `video_url` 和 `prompt`，可选加入参考素材。不传 `duration` 即保留原始时长，或明确指定新的时长。

API Playground 中的请求示例演示了这些输入。


## 注意事项

- 在参考模式下，可选的起始帧与参考图片合计不能超过 10 张。起始帧、参考图片、参考视频和主体的总数不能超过 15。主体内的图片计为一个主体，而不是单独的素材。
- 源视频、参考视频与基于视频的主体的原始时长合计最多 20 秒。每个源视频或参考视频时长必须为 3–20 秒，每个主体视频为 3–8 秒。
- Flash 不支持 `1080p`、结束帧和 `multi_prompt`，需要这些能力请使用 [Kling 4.0](/zh/api-manual/video-series/kling-4-0)。
- 参考索引从 1 开始，按对应输入数组的顺序排列。请使用可公开访问的媒体 URL，并省略未使用的可选字段。
