<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

Wan 3.0 包含三个模型，分别用于文本、首尾帧和多模态参考视频生成。

## 模型

- `wan3.0-text-to-video` — 根据必填的文本提示词生成视频
- `wan3.0-image-to-video` — 根据一到两张首尾帧图片生成视频
- `wan3.0-reference-to-video` — 根据多模态参考生成视频

## 功能

- **时长**：2–30 秒
- **分辨率**：480p、720p 或 1080p
- **首尾帧**：图片模型可使用一到两个 `image_urls`
- **生成音频**：通过 `audio` 控制输出音轨
- **多模态参考**：参考模型可使用图片、视频、音频片段、文档或公开网页
- **参考标签**：在提示词中以 `Image1`、`Video1` 或 `Audio1` 引用输入
