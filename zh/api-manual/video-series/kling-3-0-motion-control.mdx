`kling-3.0-motion-control` 结合一张参考图片和一段参考视频，将动作迁移到目标角色上。

## 模型

- **kling-3.0-motion-control** - 从参考视频到参考图片的动作迁移

## 必填参数

- **image_urls**：恰好 `1` 张参考图片
- **video_urls**：恰好 `1` 段参考视频
- **character_orientation**：`image` 或 `video`

## 可选参数

- **prompt**：可选的场景提示词
- **resolution**：`720p` 或 `1080p`。默认为 `720p`
- **kling_elements**：可选的面部一致性元素。仅在 `character_orientation=video` 时可用

## 注意事项

- 图片支持 `.jpg`、`.jpeg`、`.png`，最大 `10MB`
- 视频支持 `.mp4`、`.mov`，最大 `100MB`
- 参考视频至少 `3` 秒
- 当 `character_orientation=image` 时，参考视频不得超过 `10` 秒
- 当 `character_orientation=video` 时，参考视频不得超过 `30` 秒
- `kling_elements` 仅支持 `1` 个面部元素。每个元素需要 `frontal_image_url` 和包含 `1` 到 `3` 张图片的 `reference_image_urls`
- 使用 `kling_elements` 时，在提示词中以 `@Element1` 引用该元素
