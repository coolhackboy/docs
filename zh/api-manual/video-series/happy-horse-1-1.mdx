`happy-horse-1.1` 通过一个公开 model ID 支持文生视频、图生视频和参考生视频。

## 模型

- **happy-horse-1.1** - Alibaba Happy Horse 1.1 视频生成

## 输入模式

### 文生视频

发送 `prompt`，不带 `image_urls` 或 `reference_image_urls`。使用 `aspect_ratio`、`resolution` 和 `duration` 控制输出。

### 图生视频

发送只含一项的 `image_urls` 数组。该图片用作首帧。此模式下 `prompt` 为可选。

### 参考生视频

发送包含 1-9 张图片的 `reference_image_urls`，并且必须提供 `prompt`。

不要将 `reference_image_urls` 与 `image_urls` 同时使用。

## 必填参数

- **model**：`happy-horse-1.1`
- **input.prompt**：文生视频和参考生视频必填。图生视频可选。最大长度为 2,500 个字符。
- **input.image_urls**：图生视频必填。
- **input.reference_image_urls**：参考生视频必填。

## 可选参数

- **image_urls**：图生视频所用的首帧图片 URL 数组，只含一项
- **reference_image_urls**：参考生视频使用的 1-9 张图片
- **aspect_ratio**：仅限文生视频和参考生视频。`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`4:5`、`5:4`、`9:16` 或 `9:21`。默认为 `16:9`
- **resolution**：`720p` 或 `1080p`。默认为 `1080p`
- **duration**：`3` 到 `15` 的整数秒。默认为 `5`
- **seed**：可选，`0` 到 `2147483647` 的整数
- **enable_safety_checker**：可选布尔值

## 注意事项

- `image_urls` 必须恰好解析为一张图片，且仅用于图生视频。
- `reference_image_urls` 会选择参考生视频，不能与 `image_urls` 同时使用。
- 文生视频和参考生视频请不要传 `image_urls`，并使用 `aspect_ratio`。
