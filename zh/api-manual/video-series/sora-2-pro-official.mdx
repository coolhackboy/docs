<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

`sora-2-pro-official` 支持文生视频，以及可选的单图引导生成，时长固定为 4 秒、8 秒、12 秒、16 秒和 20 秒。

## 模型

- **sora-2-pro-official** - 官方 Sora 2 Pro 文生视频和图生视频

## 必填参数

- **prompt**：用于视频生成的文本提示词

## 可选参数

- **image_urls**：可选的参考图片数组。最多 `1` 张图片。提供此字段即启用图生视频模式
- **aspect_ratio**：文生视频为 `16:9` 或 `9:16`；图生视频为 `auto`、`16:9` 或 `9:16`。文生视频默认为 `16:9`，图生视频默认为 `auto`
- **duration**：`4`、`8`、`12`、`16` 或 `20`。默认为 `4`
- **resolution**：`720p`、`1024p` 或 `1080p`。默认为 `1024p`

## 注意事项

- `image_urls` 为可选。如果提供，仅支持一张图片，且 `image_urls[0]` 作为首帧使用。
- `aspect_ratio=auto` 仅在提供 `image_urls` 时有效。
- 本页仅介绍统一的提交请求。请通过标准的任务状态 API 查询状态。
