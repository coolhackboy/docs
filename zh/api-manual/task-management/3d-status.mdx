# 获取任务状态

查询 3D 生成任务的执行状态，并在完成后获取生成的模型文件。

## 接口

```http
GET https://api.poyo.ai/api/generate/status/{task_id}
```

## 认证

所有请求都需要 Bearer token 认证：

```bash
Authorization: Bearer YOUR_API_KEY
```

## 参数

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `task_id` | string | 是 | 提交接口返回的唯一任务标识 |

## 响应

### 成功响应（200）

```json
{
  "code": 200,
  "data": {
    "task_id": "9OTM0HH9LBS63LF0",
    "status": "finished",
    "credits_amount": 30,
    "files": [
      {
        "file_url": "https://cdn.doculator.org/3d/9OTM0HH9LBS63LF0/9OTM0HH9LBS63LF0_1.glb",
        "file_type": "3d"
      },
      {
        "file_url": "https://cdn.doculator.org/3d/9OTM0HH9LBS63LF0/9OTM0HH9LBS63LF0_2.png",
        "file_type": "image"
      },
      {
        "file_url": "https://cdn.doculator.org/3d/9OTM0HH9LBS63LF0/9OTM0HH9LBS63LF0_3.glb",
        "file_type": "3d"
      }
    ],
    "created_time": "2026-05-12T02:36:12",
    "progress": 100
  }
}
```

### 响应字段

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `code` | integer | HTTP 状态码（成功为 200） |
| `data.task_id` | string | 唯一任务标识 |
| `data.status` | string | 任务状态：`not_started`、`running`、`finished`、`failed` |
| `data.credits_amount` | number | 该任务扣除的积分 |
| `data.files` | array | 状态为 `finished` 时生成的 3D 模型、预览图和配套文件 |
| `data.files[].label` | string | 可选的文件标签，例如 `model_glb`、`thumbnail`、模型格式标签、贴图标签或动画标签 |
| `data.files[].file_url` | string | 生成文件的直链 URL |
| `data.files[].file_type` | string | 生成文件的类型：`3d`、`image` 或 `other` |
| `data.files[].format` | string | 可选的文件格式，例如 `glb`、`fbx`、`obj`、`usdz`、`stl` 或 `png` |
| `data.files[].content_type` | string | 可选，生成文件的 MIME 类型 |
| `data.files[].file_name` | string | 可选，文件名 |
| `data.files[].file_size` | integer | 可选，文件大小（字节） |
| `data.created_time` | string | 任务创建时间，ISO 8601 格式 |
| `data.progress` | number | 完成百分比（0-100） |
| `data.error_message` | string | 状态为 `failed` 时的错误说明；成功的任务不返回该字段 |

### 状态值

| 状态 | 说明 |
|--------|-------------|
| `not_started` | 任务已排队，等待处理 |
| `running` | 任务正在生成中 |
| `finished` | 任务成功完成，结果在 `files` 中 |
| `failed` | 任务失败，错误详情在 `error_message` 中 |

## 代码示例

```bash
curl -X GET https://api.poyo.ai/api/generate/status/task-unified-1757165031-uyujaw3d \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## 重要说明

<Warning>
  **内容有效期**：生成的 3D 文件在创建后 **3 天**内可访问。请及时下载并保存内容。
</Warning>

<Tip>
  **Webhook**：除了轮询，你还可以在提交任务时提供 `callback_url` 来自动接收通知。参见[3D Webhook 回调](/zh/api-manual/task-management/3d-webhooks)。
</Tip>
