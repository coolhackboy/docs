音乐和音频模型通过 `POST /api/generate/submit` 调用。在 `model` 中传入 model ID，在 `input` 中传入参数，并可选传入 `callback_url`。请求会立即返回 `task_id`，任务异步执行。

## 工作流程

Suno 与其他供应商使用不同的结果接口：

- **Suno**：轮询[查询音乐详情](/zh/api-manual/music-series/query-music-detail)，或通过 `callback_url` 接收结果（参见[音乐 Webhook](/zh/api-manual/music-series/music-webhook)）。
- **MiniMax、ElevenLabs、Google、xAI**：轮询统一的[查询任务状态](/zh/api-manual/task-management/status)，或通过 `callback_url` 接收结果（参见 [Webhook 回调](/zh/api-manual/task-management/webhooks)）。

## 注意事项

- 每个页面列出该 model ID 的参数和限制，参数在不同模型之间不通用。
