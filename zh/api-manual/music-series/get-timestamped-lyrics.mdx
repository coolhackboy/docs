2. 无论是否提供 `callback_url`，都可以通过统一的[查询音乐详情](/zh/api-manual/music-series/query-music-detail)接口获取结果。

## 使用指南

- 此接口获取已生成音轨的同步歌词及其精确时间戳
- 可用于制作卡拉 OK 式显示、字幕或歌词可视化
- 需要一个已完成且包含人声的音乐生成任务

## 参数详情

- 必填参数：

  - `task_id`：先前音乐生成任务的唯一标识

  - `audio_id`：任务结果中具体音轨的标识

- 这两个标识都可以从音乐生成接口的响应或其回调中获得

## 开发者说明

- 此接口仅适用于包含人声的音轨
- `hoot_cer`（字符错误率）值表示对齐精度，值越低表示越准确
- 使用 `waveform_data` 可在歌词旁制作音频可视化效果

## 响应字段

- `aligned_words` (array)：带时间信息的歌词单词列表
  - `word` (string)：歌词文本，可能包含 `[Verse]`、`[Chorus]` 等段落标记
  - `start_s` (number)：单词开始时间（秒）
  - `end_s` (number)：单词结束时间（秒）
  - `success` (boolean)：该单词是否对齐成功
  - `palign` (number)：对齐置信度分数

- `waveform_data` (array)：用于音频波形可视化的数值数据

- `hoot_cer` (number)：对齐精度分数（字符错误率）

- `is_streamed` (boolean)：表示该音频是否为流式音轨
