<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询音乐详情](/zh/api-manual/music-series/query-music-detail)接口获取结果。
</Tip>

可选的 `vocal_start` 和 `vocal_end` 用于选取 10–30 秒的源音频片段，必须同时提供。`style` 可用于描述期望的 Persona 风格。

## 使用指南

- 此接口从现有音轨创建可复用的音乐 Persona
- Persona 会捕捉人声风格、流派特征和音乐个性
- 创建后，可通过 `persona_id` 参数在生成音乐和延长音乐接口中使用 Persona

## 参数详情

- `task_id`（必填）：已完成的[生成](/zh/api-manual/music-series/generate-music)或[延长](/zh/api-manual/music-series/extend-music)任务的任务 ID
- `audio_id`（必填）：回调数据中具体音轨的标识
- `name`（必填）：体现音乐风格或特点的描述性名称
- `description`（必填）：详细描述，包括：
  - 流派和情绪
  - 配器偏好
  - 人声特征
  - 独特的音乐个性特点

## 开发者说明

- 每条音轨只能创建一个 Persona
- 如果该音频已存在 Persona，API 返回错误码 409
- 你可以在以下接口中使用 `persona_id`：
  - [生成音乐](/zh/api-manual/music-series/generate-music)
  - [延长音乐](/zh/api-manual/music-series/extend-music)
- 提供详细的描述，以便使用 Persona 时获得最佳效果
