## 使用指南

- 此接口为现有伴奏音轨添加 AI 生成的人声
- 上传伴奏文件，并提供歌词或人声描述
- 适合把伴奏音轨变成完整歌曲

## 参数详情

- 必填参数：

  - `upload_url`：伴奏音频文件的 URL

  - `prompt`：人声的歌词或描述

  - `title`：生成音轨的名称

  - `style`：引导人声演绎的音乐风格

  - `negative_tags`：生成时要排除的风格

- 模型选择：

  - **V6**：音乐表现力更强，人声更自然。

  - **V6_MINI**：轻量且快速。

  - **V6_WILD**：更大胆、更具辨识度的音乐表现。

  - **V5_5**：按你的独特品味调校的个性化模型。

  - **V5**：出色的音乐表现力，生成速度更快

  - **V4_5PLUS**：音色更丰富（默认）

## 开发者说明

- `prompt` 参数既是歌词，也是人声的创作方向
- 使用 `style` 指定人声演绎风格（例如 "Pop Ballad"、"Rock"、"R&B"）
- 结合 `vocal_gender` 可以更好地控制人声输出

## 可选参数

- `mv` (string)：AI 模型版本。可选值：`V4_5PLUS`（默认）、`V5`、`V5_5`、`V6`、`V6_MINI`、`V6_WILD`。

- `vocal_gender` (string)：人声性别偏好。`m` 表示男声，`f` 表示女声。注意：此参数只能提高概率，不能保证生成指定性别。

- `style_weight` (number)：对风格的遵循强度。范围 0-1，最多 2 位小数。

- `weirdness_constraint` (number)：控制创意偏离程度。范围 0-1，最多 2 位小数。

- `audio_weight` (number)：音频特征的平衡权重。范围 0-1，最多 2 位小数。
