<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询音乐详情](/zh/api-manual/music-series/query-music-detail)接口获取结果。
</Tip>

## 使用指南

- 此接口为现有音乐音轨创建翻唱版本
- 需要来自先前音乐生成任务的有效 task_id
- 翻唱版本是对原音轨的全新演绎

## 参数详情

- `task_id`（必填）：已完成的音乐生成任务的任务 ID
  - 必须是生成音乐或延长音乐接口返回的有效 task_id
  - 原任务必须已成功完成

## 开发者说明

- 每个原任务只能生成一次封面
- 处理完成后，结果通过回调 URL 发送
