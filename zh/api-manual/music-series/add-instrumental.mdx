## 使用指南

- 此接口为上传的音频文件生成音乐伴奏
- 通常配合人声分轨或旋律使用，用于制作伴奏音轨
- 适合在不需要制作人的情况下为现有录音添加器乐层

## 参数详情

- 必填参数：

  - `upload_url`：要处理的音频文件 URL

  - `title`：生成音轨的名称

  - `tags`：期望的音乐风格（例如 "relaxing, piano, soothing"）

  - `negative_tags`：要排除的风格（例如 "heavy metal, fast drums"）

- 模型选择：

  - **V6**：音乐表现力更强，人声更自然。

  - **V6_MINI**：轻量且快速。

  - **V6_WILD**：更大胆、更具辨识度的音乐表现。

  - **V5_5**：按你的独特品味调校的个性化模型。

  - **V5**：出色的音乐表现力，生成速度更快

  - **V4_5PLUS**：音色更丰富（默认）

## 开发者说明

- 使用描述性的标签来引导伴奏风格
- 组合使用正向和负向标签，以精确控制输出
- 回调机制会在三个阶段发送通知：文本生成、首条音轨完成、全部音轨完成

## 可选参数

- `mv` (string)：AI 模型版本。可选值：`V4_5PLUS`（默认）、`V5`、`V5_5`、`V6`、`V6_MINI`、`V6_WILD`。

- `vocal_gender` (string)：人声性别偏好。`m` 表示男声，`f` 表示女声。注意：此参数只能提高概率，不能保证生成指定性别。

- `style_weight` (number)：对风格的遵循强度。范围 0-1，最多 2 位小数。

- `weirdness_constraint` (number)：控制创意偏离程度。范围 0-1，最多 2 位小数。

- `audio_weight` (number)：音频特征的平衡权重。范围 0-1，最多 2 位小数。
