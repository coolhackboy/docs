图像翻译会识别一张图像中的文字并进行翻译，然后返回一张在原位置替换为译文的新图像。适用于商品图、海报、截图和营销素材。

## 模型

- **poyo-ai/image-translator** — 翻译一张图像中的文字

## 必填参数

- `image_urls` (array of strings)：只能传一个图像 URL。支持 JPEG、PNG、GIF、WebP 或 BMP，最大 50 MB。
- `target_language` (string)：目标语言，例如 `en`、`zh`、`ja`、`ko`、`fr`、`de`、`es`、`pt` 或 `ru`。

## 可选参数

- `source_language` (string)：图像中文字的语言。默认 `auto`，即自动检测语言。

## 输出

任务完成后，`files` 中返回一张译后图像，`file_type: image`。

## 示例

- **将图像翻译成日语** — 设置 `image_urls`、`source_language`、`target_language`。

## 注意事项

- 每个任务只接受一张图像。
- 图像 URL 必须可公开访问。PoYo 在提交前会检查该 URL，并拒绝无法访问、类型不受支持或超过 50 MB 的文件。
