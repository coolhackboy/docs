使用 `gpt-image-2.6-flare` 根据提示词生成一张图像，或编辑最多 16 张参考图。传入非空的 `image_urls` 数组会自动进入编辑模式；省略该字段或传入空数组则为文生图。

## 模型

- **gpt-image-2.6-flare** — GPT Image 2.6 Flare

## 必填参数

- `prompt` 必填，最多支持 32,000 个字符。

## 可选参数

- `quality`：`low`、`medium`、`high`（默认）、`xhigh` 或 `max`。
- `background`：`auto`（默认）、`transparent` 或 `opaque`。
- `output_format`：`png`（默认）、`jpeg` 或 `webp`。透明背景需要 PNG 或 WebP。
- `output_compression`：`0` 到 `100` 的整数。仅当 `output_format` 为 `jpeg` 或 `webp` 时可用，其他格式返回 400 错误。
- `mask_url`：可选的 HTTP(S) 蒙版图像 URL，用于标识要编辑的区域；需要非空的 `image_urls`。
- `moderation`：`auto`（默认）或 `low`。控制内容审核严格程度，`low` 更宽松。
- `complexity`：`low`、`medium` 或 `high`（默认）。控制模型的规划力度，不影响价格。
- 参考图必须使用 HTTP(S) URL。每次请求输出一张图像。

## 尺寸

- 文生图时 `size` 默认为 `1:1`。改图时省略 `size`，输出跟随第一张参考图的宽高比，在所选 `resolution` 档位下取最接近的支持比例。支持的比例：`1:1`、`2:3`、`3:2`、`4:3`、`3:4`、`4:5`、`5:4`、`16:9`、`9:16`、`21:9`。
- `resolution` 支持 `1K`（默认）、`2K` 和 `4K`。省略 size 时，文生图使用所选档位的正方形，改图使用第一张参考图最接近的比例。
- 显式指定 `size=auto` 时由模型决定图像尺寸（约 150 万像素），可与任意 `resolution` 搭配，按 `1K` 档计费。
- 使用宽高比时，实际像素尺寸可能因模型和每次生成而不同。请以返回图像为准确认精确尺寸；需要精确像素时请使用自定义尺寸。
- 自定义 `WIDTHxHEIGHT` 尺寸可与任意 `resolution` 搭配。两个维度都必须能被 16 整除，最长边不得超过 3840，宽高比不得超过 3:1，总像素数必须在 655,360 到 8,294,400 之间。计费档位按总像素数确定（不超过 1,572,864 为 `1K`，不超过 4,194,304 为 `2K`，更大为 `4K`），所选 `resolution` 更高时按所选档位。

## 示例

### 文生图

```json
{
  "model": "gpt-image-2.6-flare",
  "input": {
    "prompt": "A premium product photo of a silver espresso machine in a bright studio",
    "size": "16:9",
    "resolution": "2K",
    "quality": "medium"
  }
}
```

### 图像编辑

```json
{
  "model": "gpt-image-2.6-flare",
  "input": {
    "prompt": "Keep the product and replace the background with a warm modern studio",
    "image_urls": [
      "https://example.com/product.png"
    ],
    "size": "1:1",
    "quality": "high"
  }
}
```

### 蒙版编辑

```json
{
  "model": "gpt-image-2.6-flare",
  "input": {
    "prompt": "Replace only the masked area with a small vase of flowers",
    "image_urls": [
      "https://example.com/room.png"
    ],
    "mask_url": "https://example.com/mask.png",
    "size": "auto"
  }
}
```

### 透明背景

```json
{
  "model": "gpt-image-2.6-flare",
  "input": {
    "prompt": "A clean cutout of a small silver robot",
    "background": "transparent",
    "output_format": "webp",
    "size": "1:1",
    "resolution": "4K",
    "quality": "xhigh"
  }
}
```

### 压缩 JPEG

```json
{
  "model": "gpt-image-2.6-flare",
  "input": {
    "prompt": "A sunlit street market with colorful fruit stands",
    "size": "3:2",
    "resolution": "2K",
    "output_format": "jpeg",
    "output_compression": 80
  }
}
```
