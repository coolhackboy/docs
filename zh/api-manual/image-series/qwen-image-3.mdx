<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

Qwen Image 3 支持文生图和多参考图生成，适用于海报、产品视觉、文字排版和自然语言图像编辑。

## 模型

- **qwen-image-3** - 标准图像生成，支持 1K 和 2K 输出
- **qwen-image-3-pro** - 更高质量的图像生成，支持 1K 和 2K 输出

两个模型使用统一接口。文生图时省略 `image_urls`，图生图时提供 1–3 张参考图。

## 必填参数

- `prompt` 必填，最多支持 5,000 个字符。

## 可选参数

- `size` 支持 `1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`16:9`、`9:16` 和 `21:9`。
- `resolution` 支持 `1K` 和 `2K`。
- `output_format` 支持 `png` 和 `jpeg`。
- `prompt_extend` 控制自动提示词增强。
- `negative_prompt` 描述不应出现在输出中的内容。
- `seed` 接受 0 到 2,147,483,647 之间的值。
- `enable_safety_checker` 控制内容安全检查。

## 示例

### Pro 文生图示例

```json
{
  "model": "qwen-image-3-pro",
  "callback_url": "https://your-domain.com/callback",
  "input": {
    "prompt": "Create a refined bilingual technology conference poster with the headline Future Vision, elegant grid layout, blue and silver palette, realistic print texture",
    "size": "3:4",
    "resolution": "1K",
    "output_format": "png",
    "negative_prompt": "blurry, distorted typography, watermark",
    "seed": 314159
  }
}
```

### 标准版参考图示例

```json
{
  "model": "qwen-image-3",
  "input": {
    "prompt": "Transform this logo into a polished metallic badge with realistic studio lighting while preserving its recognizable shape and colors",
    "image_urls": ["https://storage.poyo.ai/logo.webp"],
    "size": "4:3",
    "resolution": "2K",
    "output_format": "jpeg",
    "prompt_extend": false
  }
}
```

### Pro 2K 参考图示例

```json
{
  "model": "qwen-image-3-pro",
  "input": {
    "prompt": "Transform this logo into a premium glass and brushed-metal app icon, preserve the original geometry and colors, dark blue studio background",
    "image_urls": ["https://storage.poyo.ai/logo.webp"],
    "size": "16:9",
    "resolution": "2K",
    "output_format": "png"
  }
}
```

### Pro 多参考图示例

```json
{
  "model": "qwen-image-3-pro",
  "input": {
    "prompt": "Combine the original logo geometry from the first reference with the brushed-metal material and lighting from the second reference, centered premium brand emblem",
    "image_urls": [
      "https://storage.poyo.ai/logo.webp",
      "https://storage.poyo.ai/qwen-image-3-pro/reference-material.jpg"
    ],
    "size": "1:1",
    "resolution": "1K",
    "output_format": "png"
  }
}
```
