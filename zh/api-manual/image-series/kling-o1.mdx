<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

## 模型

- **kling-o1-image-edit** - 基于参考图的图像编辑，可选元素引导

## 必填参数

- `prompt` - 必填的编辑提示词
- `image_urls` - 必填的参考图 URL，`1-10` 张

## 可选参数

- `elements` - 可选的元素描述数组，用于控制角色/物体。在提示词中以 `@Element1`、`@Element2` 等方式引用。推荐结构：`frontal_image_url` 填主要的人脸/物体图像，可选的 `reference_image_urls` 填其他参考视角
- `resolution` - `1K` 或 `2K`
- `size` - `auto`、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`3:2`、`2:3`、`21:9`
- `output_format` - `jpeg`、`png`、`webp`
- `n` - 输出图像数量，`1-9`

## 示例

使用统一提交接口：`POST /api/generate/submit`

```bash
curl --request POST \
  --url https://api.poyo.ai/api/generate/submit \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "kling-o1-image-edit",
    "callback_url": "https://your-domain.com/callback",
    "input": {
      "prompt": "Transform the product shot into a premium studio campaign image",
      "image_urls": ["https://example.com/reference1.png"],
      "elements": [
        {
          "frontal_image_url": "https://example.com/subject-front.png",
          "reference_image_urls": ["https://example.com/subject-side.png"]
        }
      ],
      "resolution": "2K",
      "size": "16:9",
      "output_format": "png",
      "n": 2
    }
  }'
```
