<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

通过同一个模型 ID `grok-imagine-image-2.0` 进行文生图和图像编辑。

当 `input.image_urls` 为空或省略时，模型根据提示词生成图像。当 `input.image_urls` 包含一到三张图像时，模型对这些图像进行编辑。默认宽高比为 `1:1`。

用 `input.quality` 和 `input.resolution` 控制输出档位，用 `input.n` 请求最多四张输出图像。用量取决于所选的输出数量、质量、分辨率和输入图像数量。

## 模型

- **grok-imagine-image-2.0** - 文生图和多图编辑
