<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

使用 Grok Imagine 模型生成高质量图像。支持文生图和图生图，可选指定宽高比。

图生图时，`input.image_urls` 必填，且必须是只包含一个 URL 字符串的数组，指向参考图。请提供已上传文件的 URL；支持的类型：image/jpeg、image/png、image/webp；最大大小：10.0MB。

两种模式下 `input.size` 均为可选。支持的值：`2:3`、`3:2`、`1:1`、`16:9`、`9:16`。

## 模型

- **grok-imagine-image** - 文生图和图生图
