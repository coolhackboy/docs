<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

Seedream-5.0-Flash 可根据文本生成图像，或使用最多 10 张参考图编辑图像。每次请求生成一张图像。

## 模型

- **seedream-5.0-flash** - 文生图
- **seedream-5.0-flash-edit** - 使用 1–10 张参考图进行图像编辑

## 尺寸

`input.size` 控制输出宽高比。省略时系统使用 `1:1`：

- 比例预设：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`2:3`、`3:2`、`21:9`

## 分辨率

`input.resolution` 控制输出分辨率。省略时系统使用 `1K`：

- 分辨率预设：`1K`、`1.5K`、`2K`

## 示例

使用统一提交接口：`POST /api/generate/submit`

文生图示例：

```bash
curl --request POST \
  --url https://api.poyo.ai/api/generate/submit \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "seedream-5.0-flash",
    "callback_url": "https://your-domain.com/callback",
    "input": {
      "prompt": "A colorful editorial poster for a neighborhood flower shop, with crisp typography and warm morning light",
      "size": "3:4",
      "resolution": "1.5K",
      "output_format": "png"
    }
  }'
```

编辑示例：

```bash
curl --request POST \
  --url https://api.poyo.ai/api/generate/submit \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "seedream-5.0-flash-edit",
    "input": {
      "prompt": "Place the product from the second image on the table in the first image, preserving its shape and label",
      "image_urls": [
        "https://example.com/table.jpg",
        "https://example.com/product.png"
      ],
      "size": "4:3",
      "resolution": "2K",
      "enable_safety_checker": true
    }
  }'
```
