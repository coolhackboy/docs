<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

使用 Z-Image 模型生成高质量图像。通过统一的请求结构同时支持文生图和图像编辑。

`z-image` 使用统一的请求格式：

- 省略 `input.image_urls` 时，请求按文生图处理
- 提供 `input.image_urls` 时，请求自动按图像编辑处理

## 模型

- **z-image** - 统一的文生图与图像编辑模型

## 必填参数

- `prompt` - 必填提示词，最多 `1000` 个字符

## 可选参数

- `size` - 文生图必填，图像编辑可选。支持的值：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`
- `image_urls` - 可选，用于编辑的参考图数组，必须恰好包含 `1` 个图像 URL
- `enable_safety_checker` - 可选布尔值，安全检查开关，默认为 `true`

## 示例

使用统一提交接口：`POST /api/generate/submit`

文生图示例：

```bash
curl --request POST \
  --url https://api.poyo.ai/api/generate/submit \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "z-image",
    "callback_url": "https://your-domain.com/callback",
    "input": {
      "prompt": "A serene mountain landscape at sunset with vibrant colors",
      "size": "1:1",
      "enable_safety_checker": true
    }
  }'
```

图像编辑示例：

```bash
curl --request POST \
  --url https://api.poyo.ai/api/generate/submit \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "z-image",
    "callback_url": "https://your-domain.com/callback",
    "input": {
      "prompt": "Turn this product photo into a premium studio shot with soft rim lighting",
      "image_urls": ["https://example.com/reference-image.png"],
      "size": "4:3",
      "enable_safety_checker": true
    }
  }'
```

## 注意事项

- `input.image_urls[0]` 用作编辑参考图
- 存在 `image_urls` 时，可以省略 `size`
