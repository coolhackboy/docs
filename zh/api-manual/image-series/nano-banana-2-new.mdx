<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

由 Google Gemini 3.1 Flash Image Preview 驱动的新一代 AI 图像生成。可输出原生 2K / 4K 分辨率图像，具备精准的多语言文字渲染、基于思维链的物理关系理解，并最多支持 14 张参考图。

## 模型

- **nano-banana-2-new** - 文生图和图生图生成
- **nano-banana-2-new-edit** - 高级图像编辑能力
- **nano-banana-2-official** - 文生图，支持 `output_format`、`size=auto` 以及 `0.5K` / `1K` / `2K` / `4K` 分辨率
- **nano-banana-2-official-edit** - 图像编辑，最多支持 14 张参考图，并支持 `output_format`、`size=auto` 以及 `0.5K` / `1K` / `2K` / `4K` 分辨率
