<Tip>
1. 提交后会返回 `task_id`。如果提供了 `callback_url`，当任务状态变为 `finished` 或 `failed` 时，系统会向 `callback_url` 发送 POST 请求。
2. 无论是否提供 `callback_url`，都可以通过统一的[查询任务状态](/zh/api-manual/task-management/status)接口获取结果。
</Tip>

Flux Kontext 由 Black Forest Labs 提供支持。它通过同一个统一提交接口同时支持文生图和图像编辑。

## 模型

- **flux-kontext-pro** - Flux Kontext Pro 文生图
- **flux-kontext-pro-edit** - Flux Kontext Pro 图像编辑，`image_urls` 必填
- **flux-kontext-max** - Flux Kontext Max 文生图
- **flux-kontext-max-edit** - Flux Kontext Max 图像编辑，`image_urls` 必填

## 注意事项

- `size` 支持 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`21:9`、`9:21`
- `output_format` 支持 `png`、`jpg`
- 编辑模型必须提供 `image_urls`
- 只有 `image_urls[0]` 会被用作输入图像
- 其他下游字段在当前 API 中未开放，使用系统默认值
