PoYo 通过四种 API 格式提供多家厂商的 LLM。每个请求在 `model` 中传入 model id（Gemini Native 则放在 URL 路径中）。一个模型只接受下表中标记的格式。

## API 格式

- [Chat Completions](/zh/api-manual/chat-series/chat-completions) — `POST /v1/chat/completions`，OpenAI Chat Completions 请求结构
- [Responses](/zh/api-manual/chat-series/responses) — `POST /v1/responses`，OpenAI Responses 请求结构
- [Anthropic Messages](/zh/api-manual/chat-series/claude-messages) — `POST /v1/messages`，Anthropic Messages 请求结构
- [Gemini Native](/zh/api-manual/chat-series/gemini-native-format) — `POST /v1beta/models/{model}:{method}`，Google `generateContent` 请求结构

所有模型都支持流式输出：使用各格式的 `stream` 选项，Gemini Native 则使用 `streamGenerateContent`。

## 注意事项

- 只把模型发送到为其标记的格式。例如 `gpt-5-6-sol` 只能用于 Responses。其他格式会返回 HTTP 400，并列出支持的 URI。
- 使用 `Authorization: Bearer YOUR_API_KEY` 认证。Anthropic Messages 也接受 `x-api-key`。
- LLM 响应直接以各格式的原生结构返回，不使用生成类任务的 `code` / `data` 包装。流式事件格式见各格式页。
- LLM 接口目前没有速率限制。
